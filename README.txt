APEXDESIGNZ SEO update package

Files:
- index.html: original website HTML with head-level SEO metadata and structured data added. Existing CSS, page layout and JavaScript are preserved.
- sitemap.xml: sitemap for the single public homepage URL.
- robots.txt: allows crawling and points crawlers to sitemap.xml.

Deploy all three files to the ROOT of the GitHub repository that publishes https://apexdesignz.github.io/. Keep index.html as the homepage filename. Do not upload only the HTML: robots.txt and sitemap.xml must also be at the repository root.

After deployment, check these URLs in a browser:
https://apexdesignz.github.io/
https://apexdesignz.github.io/robots.txt
https://apexdesignz.github.io/sitemap.xml

Then add https://apexdesignz.github.io/ as a URL-prefix property in Google Search Console, verify ownership, submit sitemap.xml, and use URL Inspection > Test Live URL > Request Indexing. Search Console is required to verify actual Google indexing; metadata alone cannot guarantee ranking or indexing.
